# Security Policy

Please do not report security-sensitive issues in public GitHub Issues.

For suspected security problems, contact SnipGeek through:

* Website: https://snipgeek.com
* GitHub owner/repo: https://github.com/ieproject-app/widget-music

Include a concise description, affected version, reproduction steps, and whether the issue requires local user interaction. Please avoid publishing exploit details until there has been time to investigate and prepare a fix.

SnipTune 10 is distributed without warranty under the MIT License, but security reports are still taken seriously.
