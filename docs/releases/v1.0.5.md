# SnipTune 10 1.0.5

This release prepares SnipTune 10 for public use and improves first-run experience on Windows 10.

## Highlights

* Faster first activation after login with per-user host prewarm.
* Manual taskbar toolbar activation flow documented with screenshots.
* Compact and full taskbar modes with smoother native visual behavior.
* Improved Windows 10 taskbar background matching.
* Keyboard and screen reader accessibility support.
* Hardened per-user installer, update, unregister, and uninstall flow.
* Public README, MIT License, contribution guide, issue templates, and release documentation.

## Install

Download `SnipTune10Setup-1.0.5-x64.exe`, run it on Windows 10 x64, then enable the widget from:

```text
Right click taskbar > Toolbars > SnipTune 10
```

If Windows shows a confirmation prompt, choose `Yes`.
