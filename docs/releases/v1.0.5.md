# SnipTune 10 1.0.5

This release prepares SnipTune 10 for public use and improves first-run experience on Windows 10.

## Highlights

* Faster first activation after login with per-user host prewarm.
* Manual taskbar toolbar activation flow documented with screenshots.
* Compact and full taskbar modes with smoother native visual behavior.
* Improved Windows 10 taskbar background matching.
* Keyboard and screen reader accessibility support.
* Hardened per-user installer, update, unregister, and uninstall flow.
* Public README, MIT License, contribution guide, issue templates, and release documentation.
* Clearer public-facing positioning for a real Windows 10 media control use case.

## Why This Release Matters

SnipTune 10 is not just a demo build. v1.0.5 establishes the project as a usable public release with a documented install path, a stable per-user installer flow, accessibility support, and maintenance notes that make future updates easier to validate.

It is designed for users who want native media controls in the Windows 10 taskbar while keeping the desktop lightweight and familiar.

## Install

Download `SnipTune10Setup-1.0.5-x64.exe`, run it on Windows 10 x64, then enable the widget from:

```text
Right click taskbar > Toolbars > SnipTune 10
```

If Windows shows a confirmation prompt, choose `Yes`.

## Assets

## Primary Use Case

This release is intended for people who listen to media while working on Windows 10 and want a compact native taskbar control surface for play, pause, next, previous, and basic status visibility.
